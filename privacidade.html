Política de Privacidade

Última atualização: 15 de outubro de 2026

Esta política explica como o Jesus é Pop (jesusepop.com) trata os dados do aplicativo "Jesus e Pop Metricas", usado apenas pela equipe do Jesus é Pop para acompanhar os próprios canais no YouTube.

O que o aplicativo acessa

O aplicativo se conecta à API do YouTube e à API do YouTube Analytics, com autorização do dono dos canais, para ler as estatísticas dos canais Jesus é Pop e Jesús es Pop: inscritos, visualizações, tempo de exibição, retenção e dados dos vídeos publicados. Ele também pode publicar comentários nos vídeos desses canais.

O que o aplicativo não faz

  • Não acessa dados de outras pessoas ou de outros canais.
  • Não coleta dados de quem assiste aos vídeos.
  • Não vende, aluga nem compartilha dados com terceiros.
  • Não usa os dados para publicidade.

Onde os dados ficam

As estatísticas ficam guardadas em um computador da equipe, usadas só para análise interna de desempenho dos vídeos. As credenciais de acesso ficam protegidas no mesmo computador e podem ser revogadas a qualquer momento em https://myaccount.google.com/permissions.

Uso de dados do Google

O uso de informações recebidas das APIs do Google segue a Política de Dados do Usuário dos Serviços de API do Google, incluindo os requisitos de Uso Limitado. Este aplicativo usa os Serviços de API do YouTube, e quem o utiliza também está sujeito aos Termos de Serviço do YouTube (https://www.youtube.com/t/terms) e à Política de Privacidade do Google (https://policies.google.com/privacy).
